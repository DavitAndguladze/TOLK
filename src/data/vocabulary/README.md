# English frequency ranks

`english-2018.json` derives the first 10,000 rows, in their original frequency order, from Hermit Dave's FrequencyWords English OpenSubtitles 2018 list:

- Source: https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/en/en_50k.txt
- Attribution/provenance: https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/README.md
- Dataset license: Creative Commons Attribution-ShareAlike 4.0, https://creativecommons.org/licenses/by-sa/4.0/
- Changes: retained the first 10,000 rows, removed occurrence counts, and converted words to 1-based rank entries in JSON. This derived dataset remains CC BY-SA 4.0; the license statement applies to this data, not unrelated application code.

These are frequency ranks from subtitle usage, not a pedagogically validated reading-level scale. TOLK's existing Level thresholds use this named, reproducible source. Required character names and explicitly retained teaching/Graduated Words are separate, visible exceptions in the validation policy; unranked words are not silently considered common.
